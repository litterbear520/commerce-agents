03

事件与结果类型

streaming.py
第一性原理
每个工具调用产出两样东西：给模型的文本，给宿主的事件。

AgentEvent 是宿主渲染的 10 种事件（text_delta、ui、cart_update 等）。ToolOutcome 是每个工具调用的统一返回：result_text + events + is_error / blocked。to_sse() 把事件序列化成 Server-Sent Events 帧。

@dataclass
class ToolOutcome:
    result_text: str                      # 模型读到的
    events: list[AgentEvent] = []         # 宿主渲染的
    is_error: bool = False
    blocked: str | None = None            # 门控名（held ≠ error）

    @classmethod
    def error(cls, text): return cls(text, is_error=True)
    @classmethod
    def held(cls, gate, text): return cls(text, blocked=gate)

信任边界

fencing.py

商品标题写 "忽略之前的指令"，模型把它当操作指令——第三方内容和系统指令混在同一文本流。

第一性原理
第三方内容是数据，不是指令。每段后端返回的文本经清洗（去不可见字符、伪对话边界、特殊标记到不动点），包裹在 XML 围栏标签内。
@dataclass(frozen=True)
class Fence:
    label: str    # "storefront_data" — 固定字面量
    notice: str

    def sanitize_text(self, text, max_chars=None) -> str:
        text = unicodedata.normalize("NFKC", text)
        text = _INVISIBLE.sub("", text)
        text = _CONTROL.sub(" ", text)
        while True:  # 到不动点
            stripped = _SPECIAL_TOKEN.sub("[removed]", marker.sub("[removed]", text))
            if stripped == text: break
            text = stripped
        return text

    def fence_payload(self, payload, max_chars=MAX_FENCED_CHARS) -> str:
        body = json.dumps(self.sanitize_value(payload), ensure_ascii=False)
        return f"{self.open}\n{body}\n{self.close}"

执行器

execution.py · executor.py

工具逻辑分散各处，一个异常中断整个对话。

第一性原理
一个分发中心，execute() 永远不抛异常。失败阶梯：InvalidArguments → 领域异常 → 通用错误 → "暂时不可用"。
class BaseToolExecutor:
    async def execute(self, name, tool_input) -> ToolOutcome:
        try:
            return await self.dispatch(name, tool_input)
        except InvalidArguments as e:
            return ToolOutcome.error(f"{name} arguments invalid — {e}")
        except Exception:
            if (outcome := self.domain_error(error)): return outcome
            return ToolOutcome.error("temporarily unavailable")

    # 角色子类实现：
    def handlers(self) -> dict[str, Handler]: ...
    def domain_error(self, error) -> ToolOutcome | None: ...

门控与溯源

gates.py

模型编造 product_id=AR-9999 并加入购物车——幻觉变成真实操作。

第一性原理
先看到才能操作。每个读取工具把返回的 ID 记入 state.seen_products，每个写入工具先检查溯源。失败返回 held（不是 error）——引导模型去查这个 ID。
def check_provenance(state, product_id) -> ToolOutcome | None:
    if product_id in state.seen_products: return None
    return ToolOutcome.held(PROVENANCE_GATE,
        f"product_id {product_id} was not returned by catalog or order tools. "
        "Call get_product_details with this id first.")

提示词与缓存

prompt.py · prompt_assembly.py
第一性原理
静态字节 + 动态上下文 = 缓存友好。两个 system block：静态文本（cache_control: ephemeral）+ 动态上下文（客户资料、购物车、时钟取整到小时）。工具列表最后一项加断点。对话中滚动断点让前面的轮次变成缓存读取。
def build_system_blocks(static_text, context):
    return [
        {"type": "text", "text": static_text,
         "cache_control": {"type": "ephemeral"}},  # 所有轮次缓存
        {"type": "text", "text": context},           # 状态不变则不重读
    ]

第一性原理

class ShoppingAgent:
    async def stream_turn(self, messages, session, state):
        preferences, cart, memory_facts, account = await self._prefetch(session)
        context = build_dynamic_context(preferences=preferences, ...)
        system = build_system_blocks(self._static_system, context)
        forced_tool = first_forced_tool(GROUNDING_RULES, self.config,
                                        latest_user_text(messages), state)
        for round_index in range(self.config.max_tool_iterations + 1):
            dispatcher = EagerDispatcher(executor.execute, ...)
            streamed = StreamedRound(specs=self._specs, ...)
            async with self.client.messages.stream(**request) as stream:
                async for event in streamed.relay(stream, dispatcher, ...):
                    yield event
            if round_closes_turn(..., executor.ends_clean): break
        await self.update_memory(messages, session)
